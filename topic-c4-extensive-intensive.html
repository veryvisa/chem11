📌 Key points要点

⭐ Must know必须记住
  • Extensive = depends on amount (mass, volume, length, surface area).广延＝与量有关（质量、体积、长度、表面积）。
  • Intensive = amount does not matter (density, mp, bp, colour, temperature, viscosity).强度＝与量无关（密度、熔点、沸点、颜色、温度、黏度）。
  • Test: cut it in half — value halves → E; stays the same → I.判断：切一半——数值减半 → 广延；不变 → 强度。

💡 A gold ring and a gold bar have very different masses, yet both have exactly the same density — so which properties care about "how much" and which do not?金戒指和金条的质量差很多，密度却完全一样——哪些性质跟「有多少」有关，哪些无关？

  1. Extensive and intensive are the two types of PHYSICAL property. The question is: does the value depend on how much substance you have?广延性质和强度性质是物理性质的两种类型。关键问题：这个数值跟物质的多少有没有关系？
  2. Extensive property: depends on the amount. More stuff → bigger value. Examples: mass, volume, length, surface area, total mass of a group.广延性质：随物质的量变化。东西越多 → 数值越大。例如：质量、体积、长度、表面积、一组东西的总质量。
  3. Intensive property: does NOT depend on the amount. Examples: density, melting point, boiling point, colour, temperature, viscosity.强度性质：与物质的量无关。例如：密度、熔点、沸点、颜色、温度、黏度。
  4. Half-sample test: imagine cutting the sample in half. If the value halves → extensive. If it stays the same → intensive.「切一半」测试：想象把样品切成两半。数值也减半 → 广延性质；数值不变 → 强度性质。

🧮 Key formulas关键公式

D=Vm​
Density = mass ÷ volume: extensive ÷ extensive gives an intensive property密度＝质量÷体积：广延÷广延，得到强度性质
🎯 Test tip考试提示
On a list question, write E or I quickly using the half-sample test. Watch for "total" (always E) and for temperature (always I).列表题用「切一半」快速写 E 或 I。注意「总……」（一定是 E）和温度（一定是 I）。

🔍 Common mistakes常见错误

⚠️ Quick list速查

  • Calling temperature extensive because a bigger pot "has more heat". Temperature is the same whether you have a cup or a bathtub at 40 °C → intensive.认为大锅「热量更多」所以温度是广延性质。一杯水和一缸水都可以是 40 °C → 温度是强度性质。
  • Calling density extensive because a big block is heavier. Heavier is mass; density stays the same.因为大块更重就把密度当成广延性质。更重的是质量，密度不变。
  • Forgetting the word "total": "total length" or "total mass" of something is extensive.忽略「总」字：某物的「总长度」「总质量」都是广延性质。

Extensive: mass, volume. Intensive: temperature, colour, melting point. Compare intensive ones, e.g. melting point and colour (or density).广延：质量、体积。强度：温度、颜色、熔点。要比较强度性质，例如熔点和颜色（或密度）。
  1. A bigger cube has more mass and volume → extensive. Temperature, colour, melting point do not depend on size → intensive.更大的冰块质量和体积更大 → 广延。温度、颜色、熔点与大小无关 → 强度。
  2. To identify the substance use intensive properties such as melting point and colour (density also works). Temperature is intensive but tells you about conditions, not identity.鉴别物质要用强度性质，比如熔点和颜色（密度也可以）。温度虽是强度性质，但反映的是所处条件，不是物质身份。

💡 Key idea解题思路
Only intensive properties identify a substance — extensive ones change with sample size.只有强度性质能鉴别物质——广延性质会随样品大小变化。
🔀 Other ways to think不同的思考方式

  • Think like a detective: a fingerprint must not change with size → intensive.像侦探一样想：「指纹」不能随大小改变 → 用强度性质。
