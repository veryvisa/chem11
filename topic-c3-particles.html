📌 Key points要点

⭐ Must know必须记住
  • Charge → ion. Lone symbol / "one particle" → atom.有电荷→离子。单个符号／「一个粒子」→原子。
  • 2+ atoms, one type → molecule + element (OX2​). 2+ types → molecule + compound (HX2​O).2 个以上原子、一种→分子＋元素（OX2​）。两种以上→分子＋化合物（HX2​O）。
  • Element = one TYPE of atom, not one atom. Class key: NaCl → compound only.元素＝一「种」原子，不是一个原子。讲义答案：NaCl 只是化合物。

💡 OX2​, COX2​, NaCl, Fe, SOX4​X2− — the test gives you a list of formulas and asks: atom, element, molecule, compound or ion? Some get two labels. Four quick questions sort every one.OX2​、COX2​、NaCl、Fe、SOX4​X2−——考试给一串化学式，问：原子、元素、分子、化合物还是离子？有的要写两个标签。四个小问题就能全部分清。

  1. An atom is the smallest particle of an element that still has that element's properties ("one gold particle"). Atoms are made of protons, neutrons and electrons; about 50 million lined up make 1 cm.原子＝仍保持元素性质的最小粒子（「一个金粒子」）。原子由质子、中子、电子构成；约 5000 万个排成一行才 1 cm 长。
  2. An element is a pure substance made of only one type of atom — one TYPE, not one atom: OX2​, NX2​, HX2​ and a whole bar of gold are all elements.元素（单质）＝只由一种原子构成的纯净物——是一种「类型」，不是一个原子：OX2​、NX2​、HX2​ 和一整块金都是元素。
  3. A molecule is 2 or more atoms (same OR different types) joined by bonds. A compound is a pure substance of 2 or more different types of atoms chemically combined in a fixed way (HX2​O, NaCl, NaHCOX3​).分子＝2 个或以上原子（同种或不同种）通过化学键连在一起。化合物＝由 2 种或以上不同原子按固定方式化学结合而成的纯净物（HX2​O、NaCl、NaHCOX3​）。
  4. An ion is a particle with an electric charge — you will see a + or − in the formula (NOX3​X−, SOX4​X2−, NaX+).离子＝带电荷的粒子——化学式上会有 + 或 −（NOX3​X−、SOX4​X2−、NaX+）。
🟡 How your class notes say it课堂讲义的说法
Your class answer key labels a lone symbol like Fe or Cl as an atom, labels O2 and F2 as both molecule and element, and labels NaCl as a compound only. Many textbooks would say Fe can also mean the element iron, and that NaCl is an ionic compound made of ions, not molecules — which is why NaCl gets only "C" even though the class notes box says "all compounds are molecules". On this test use the class labels.课堂答案把 Fe、Cl 这样的单个符号标为原子，把 O2、F2 标为分子兼元素，把 NaCl 只标为化合物。很多教材会说 Fe 也可以指铁这种元素，而 NaCl 是由离子构成的离子化合物、不是分子——这也是为什么讲义方框写着「所有化合物都是分子」，NaCl 却只标「C」。考试按讲义的标签答。
🎯 Test tip考试提示
Write the letters (A, E, M, C, I) beside each formula, and give TWO letters when two apply — the class key expects "M, E" for OX2​ and "M, C" for HX2​O. Check for a charge before anything else.在每个化学式旁写字母（A、E、M、C、I），适用两个就写两个——讲义答案中 OX2​ 是「M、E」，HX2​O 是「M、C」。先看有没有电荷。

Example 2例 2L3 Connect会用2 methods种解法
A student says: "OX2​ cannot be an element because it has two atoms." Explain the mistake.学生说：「OX2​ 有两个原子，所以不可能是元素。」指出错误所在。
  1. O₂ contains only oxygen atoms → 1 type → element.O₂ 只含氧原子→1 种→元素。
  2. Its 2 atoms are bonded → it is also a molecule. Labels: M, E.它的 2 个原子相互成键→也是分子。标签：M、E。
  1. A 10 g piece of gold is a huge number of gold atoms, yet it is the element gold.10 g 的金块含有极多金原子，但它就是金这种元素。

Answer答案
Element means one type of atom, not one atom; OX2​ is a molecule and an element.元素指一种原子，而不是一个原子；OX2​ 既是分子又是元素。

🔍 Common mistakes常见错误

⚠️ Quick list速查

  • Thinking an element must be a single atom. OX2​ and FX2​ are elements (and molecules).以为元素必须是一个原子。OX2​、FX2​ 都是元素（也是分子）。
  • Missing the charge: SOX4​X2− is an ion, not a compound — always check for + or − first.漏看电荷：SOX4​X2− 是离子，不是化合物——先检查有没有 + 或 −。
  • Writing only one label when two apply: HX2​O, CHX4​, NHX3​ are both M and C.该写两个标签只写一个：HX2​O、CHX4​、NHX3​ 都是 M 和 C。
  • Calling a compound anything with 2+ atoms: a compound needs 2+ DIFFERENT types (NX2​ is not a compound).把含 2 个以上原子的都叫化合物：化合物需要 2 种以上「不同」原子（NX2​ 不是化合物）。

Does a molecule need different types of atom?分子一定要有不同种原子吗？
No. NX2​ is a molecule (2 bonded atoms) but only one type of atom, so it is an element, not a compound. NHX3​ has two types, so it is both a molecule and a compound.不是。NX2​ 是分子（2 个原子成键），但只有一种原子，所以是元素而不是化合物。NHX3​ 有两种原子，所以既是分子又是化合物。
  1. NX2​: molecule + element.NX2​：分子＋元素。
  2. NHX3​: molecule + compound. So only some molecules are compounds.NHX3​：分子＋化合物。所以只有部分分子是化合物。

What does a compound need that OX3​ lacks?化合物需要什么，而 OX3​ 没有？
OX3​ is a molecule and an element (M, E). It has only one type of atom; a compound needs 2+ different types. The number of atoms and its different behaviour do not make it a compound.OX3​ 是分子和元素（M、E）。它只有一种原子；化合物需要 2 种以上不同原子。原子个数和性质不同都不能使它成为化合物。
